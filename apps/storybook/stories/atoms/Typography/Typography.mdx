# Typography Atom

The Typography atoms (H1, P) provide consistent text styling.

## Usage

```tsx
import { H1, P } from '@bench-skills-up/ui-components'

export function MyComponent() {
  return (
    <div>
      <H1>Main Heading</H1>
      <P>Paragraph content here</P>
    </div>
  )
}
```

## Components

### H1
- Used for main headings
- 24px font size
- No default margin

### P
- Used for paragraph text
- Default 8px vertical margin
- Standard line height

## Features

- Consistent typography across application
- No default browser margins for better control
- Clean and minimal styling
