# Input Atom

The Input atom is a text input field with custom styling.

## Usage

```tsx
import { Input } from '@bench-skills-up/ui-components'

export function MyComponent() {
  return <Input placeholder="Enter text" />
}
```

## Props

Accepts all standard HTML input attributes:
- `type`: input type (text, email, password, etc.)
- `placeholder`: placeholder text
- `disabled`: disable the input
- `value`: input value
- `onChange`: change handler

## Features

- Custom styling with rounded corners
- Subtle border
- Consistent padding
- Supports all standard input types
