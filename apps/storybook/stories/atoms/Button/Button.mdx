# Button Atom

The Button atom is a fundamental UI element used for user interactions.

## Usage

```tsx
import { Button } from '@bench-skills-up/ui-components'

export function MyComponent() {
  return <Button>Click me</Button>
}
```

## Props

- `children`: React.ReactNode - Content inside the button
- `onClick`: React.MouseEventHandler - Click handler function

## Features

- Primary color from theme tokens
- Customizable click handlers
- Supports all React button props
