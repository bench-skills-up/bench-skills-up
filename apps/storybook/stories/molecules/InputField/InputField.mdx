# InputField Molecule

The InputField molecule combines an Input atom with a label and optional hint text.

## Usage

```tsx
<div style={{ display: 'flex', flexDirection: 'column', gap: '6px' }}>
  <label htmlFor="email">Email</label>
  <Input id="email" type="email" placeholder="Enter email" />
  <small>We'll never share your email.</small>
</div>
```

## Components

- Input (atom)
- Label element
- Optional hint/help text
- Optional error message

## Features

- Combines form inputs with labels
- Support for hints and error messages
- Accessible form field structure
