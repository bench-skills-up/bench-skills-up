# ButtonGroup Molecule

The ButtonGroup molecule combines multiple Button atoms for related actions.

## Usage

```tsx
<div style={{ display: 'flex', gap: '8px' }}>
  <Button>Cancel</Button>
  <Button>Save</Button>
</div>
```

## Patterns

- **Horizontal**: Actions side-by-side
- **Vertical**: Stacked actions
- **ActionBar**: Buttons separated across space

## Features

- Consistent spacing between buttons
- Flexible layout options
- Semantic grouping of related actions
