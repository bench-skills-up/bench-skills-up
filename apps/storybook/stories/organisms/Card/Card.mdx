# Card Organism

The Card organism is a complex container that combines multiple atoms and molecules for rich content display.

## Usage

```tsx
import { Card } from '@bench-skills-up/ui-components'
import { H1, P, Badge } from '@bench-skills-up/ui-components'

export function CardExample() {
  return (
    <Card>
      <div style={{ padding: '16px' }}>
        <H1>Title</H1>
        <Badge>New</Badge>
        <P>Content here</P>
      </div>
    </Card>
  )
}
```

## Use Cases

- Product cards in grids
- Blog post previews
- Feature cards
- Content containers with metadata

## Features

- Subtle shadow for depth
- White background with rounded corners
- Flexible content structure
- Perfect for organizing complex content
