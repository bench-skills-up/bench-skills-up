# Form Organism

The Form organism combines multiple Input fields, Labels, and Buttons to create complete form layouts.

## Usage

```tsx
import { Input } from '@bench-skills-up/ui-components'
import { Button } from '@bench-skills-up/ui-components'

export function LoginForm() {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')

  return (
    <form style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
      <div>
        <label>Email</label>
        <Input type="email" value={email} onChange={(e) => setEmail(e.target.value)} />
      </div>
      
      <div>
        <label>Password</label>
        <Input type="password" value={password} onChange={(e) => setPassword(e.target.value)} />
      </div>

      <Button>Sign In</Button>
    </form>
  )
}
```

## Components Used

- Input (atoms)
- Button (atoms)
- Typography (atoms)
- InputField (molecules)
- ButtonGroup (molecules)
